PANDUAN LOGO NAVBAR KONTRAKAN COFFEE
======================================

Letakkan file foto / logo kafe Anda di folder ini:
Path lengkap: frontend/public/images/logo.png

Ketentuan & Saran File:
1. Nama file utama: logo.png
   (Sistem juga mendukung fallback: logo.jpg, logo.jpeg, logo.webp, atau logo.svg)
2. Format disarankan: PNG dengan background transparan (agar serasi dengan warna navbar cokelat tua kafe).
3. Dimensi disarankan:
   - Tipe horizontal: 320 x 80 px (atau 640 x 160 px untuk Retina / High-DPI).
   - Tipe emblem bulat / kotak: 160 x 160 px (atau 320 x 320 px).
4. Di dalam website, tinggi logo telah disesuaikan otomatis (h-10 sm:h-12) dengan fit object-contain sehingga tidak akan terdistorsi atau gepeng.
